About Smart Shopping Intelligence System

B.Tech Artificial Intelligence & Data Science — Applied Market Basket Analysis & Recommender Platform.

01 · Problem Statement

Why Retail Needs Basket Intelligence

Modern e-commerce and supermarket catalogs contain hundreds of SKUs, yet static storefronts treat every item in isolation. Without analyzing historical co-purchase behavior, stores miss high-converting cross-sell bundles, optimal shelf placements, and personalized cart suggestions.

02 · Project Objectives

Core Engineering Goals

  • Preprocess and one-hot encode raw multi-item shopping baskets using Pandas.
  • Discover frequent itemsets and association rules via the Apriori algorithm.
  • Deliver real-time, explainable recommendations inside product views and the cart.
  • Visualize trends and rule quality dynamically using Plotly and SQLite.

04 · Machine Learning Methodology

How the Apriori Algorithm Powers Recommendations

The Apriori algorithm exploits the downward-closure property: any subset of a frequent itemset must also be frequent. Our pipeline loads {{ model_stats.total_transactions }} historical and live checkout baskets from SQLite, removes duplicates, encodes transactions into a boolean matrix, mines frequent itemsets, and ranks candidate rules using three core metrics:

Support(A → B) = P(A ∪ B) = Transactions containing both A and B / Total Transactions
Confidence(A → B) = P(B | A) = Support(A ∪ B) / Support(A)
Lift(A → B) = Confidence(A → B) / Support(B)   (Lift > 1.0 indicates positive co-purchase affinity)
05 · End-to-End Pipeline

7-Stage ML Workflow

  1. Load transaction history from SQLite & CSV.
  2. Clean tokens, validate SKUs, deduplicate per basket.
  3. One-hot encode via TransactionEncoder.
  4. Extract frequent itemsets with Apriori.
  5. Generate association rules filtered by confidence & lift.
  6. Retrain automatically after every completed checkout.
  7. Serve human-readable explanations to the UI.
